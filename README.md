# PaperLens 📄

面向高校学生的中文论文阅读助手（第一版原型）：粘贴论文文本或上传文字型 PDF，即可获得**四部分中文摘要**（研究问题 / 研究方法 / 主要结果 / 局限性）和**基于论文内容的问答**。摘要和回答会附上原文依据；证据不足时会明确说明"在提供的论文内容中没有找到足够依据"，不会编造。

---

## 一、需要安装什么软件

只需要一个软件：**Node.js**（它已经自带了 npm，不需要单独安装）。

- 不需要 Python、数据库、Docker 或 Git。

如果你还没装 Node.js：

1. 打开官网 https://nodejs.org/zh-cn
2. 点击绿色的 **LTS（长期支持版）** 按钮下载 Windows 安装包（.msi）
3. 双击安装包，一路点"下一步"即可（保持默认选项）

## 二、如何确认软件已正确安装

1. 按 `Win + R`，输入 `cmd`，回车，打开黑色命令行窗口
2. 输入下面命令，回车：

```
node --version
```

3. 如果显示类似 `v20.x.x` 或更高的版本号，说明安装成功。再输入：

```
npm --version
```

显示版本号（如 `10.x.x`）就没问题了。

> 如果提示"不是内部或外部命令"，请关闭命令行窗口重新打开再试；还不行就重新安装 Node.js 并重启电脑。

## 三、如何启动项目

在本项目文件夹（PaperLens）下操作：

**第一次使用**（只做一次）：

1. 在命令行中进入项目文件夹（把路径换成你实际的位置）：

```
cd /d d:\项目\PaperLens
```

2. 安装依赖（会自动下载需要的组件到 node_modules 文件夹）：

```
npm install
```

**每次启动**：

```
npm start
```

看到 `PaperLens 已启动: http://localhost:3000` 后，用浏览器打开：

👉 **http://localhost:3000**

停止服务：在命令行窗口按 `Ctrl + C`。

## 四、如何配置模型服务和 API Key

没有配置 API Key 时，页面也能打开、也能解析 PDF，但会提示"模型服务未配置"，**不会**假装生成 AI 结果。

配置步骤：

1. 把项目里的 `.env.example` 文件**复制一份**，改名为 `.env`
2. 用记事本或 Trae 打开 `.env`，填入三项：

```
LLM_API_KEY=你的真实密钥
LLM_BASE_URL=模型接口地址
LLM_MODEL=模型名称
```

3. 本项目支持所有 **OpenAI 兼容接口**的服务。以 DeepSeek 为例（需你自行到其官网注册获取密钥，本项目不会替你创建任何账户）：

```
LLM_API_KEY=sk-你的密钥
LLM_BASE_URL=https://api.deepseek.com/v1/chat/completions
LLM_MODEL=deepseek-chat
```

4. 保存 `.env` 后，**重启服务**（Ctrl+C 再 `npm start`）生效。

🔒 **安全提醒**：
- `.env` 已被 `.gitignore` 忽略，不会被提交到 GitHub
- 不要把 `.env` 发给任何人，不要把密钥写进代码或聊天记录
- 想换模型服务时，改 `.env` 里的三项即可；代码层面的修改都集中在 `llm.js` 一个文件里

## 五、如何使用粘贴文本和 PDF

**方式 A：粘贴文本（推荐，永远可用）**
1. 打开论文（PDF/网页均可），选中文字并复制
2. 粘贴到首页"粘贴论文文本"框里
3. 也可以先点"填入演示文本"体验一遍流程（内容已标注为演示）

**方式 B：上传 PDF**
1. 点击"上传 PDF"选项卡，选择文件（不超过 20MB）
2. 系统会逐页提取文字并标注页码，自动填入文本框
3. 如果提示"没有提取到任何文字"，说明是扫描版（图片型）PDF——本版本不支持 OCR，请改用方式 A

然后点击"生成摘要"，或在底部输入问题（回车也可提交）。

## 六、常见错误怎么处理

| 现象 | 原因和解决办法 |
| --- | --- |
| `npm install` 报错/卡住 | 检查网络；可换国内镜像：`npm config set registry https://registry.npmmirror.com` 后再试 |
| 浏览器打不开 localhost:3000 | 确认命令行窗口里显示"已启动"且窗口没被关闭；确认地址是 http 不是 https |
| 页面提示"模型服务未配置" | 还没配置 `.env`，按第四节操作并**重启服务** |
| 提示"模型服务返回错误 HTTP 401/403" | API Key 错误或过期，检查 `.env` 里的密钥 |
| 提示"模型服务返回错误 HTTP 429" | 调用太频繁或余额不足，稍后再试或检查账户 |
| 摘要一直是"思考中"然后报错 | 论文太长导致超时，先粘贴部分章节（如摘要+方法+结果） |
| PDF 提示加密/无法解析/没有文字 | 见第五节方式 B 第 3 条，改用粘贴文本 |

## 七、当前限制和隐私说明

**当前限制**
- 扫描版（图片型）PDF 不支持：没有 OCR，提取不到文字
- 加密 PDF 不支持
- 论文超长时会截断（约前 2.4 万字），可能遗漏后文内容
- 没有数据库：刷新页面后内容不保存
- 每次只能处理一篇论文，无多论文对比
- AI 输出**可能不准确**，所有摘要和回答都应与论文原文核对

**隐私说明**
- 上传的 PDF 只在内存中解析，不写盘、不保存
- 你的论文文本会发送给 `.env` 中配置的那个模型服务（用于生成摘要/回答），请注意该服务的隐私政策；涉密论文请勿使用
- API Key 只保存在你自己电脑的 `.env` 文件里
